Empty your locker before it locks.

My university's Blackboard has no export button, and it has already locked 5 of my 17 courses. Takehome sends a TinyFish Agent through the portal on my own saved sign-in and brings everything home: one clean JSON file, CSV files and the documents. Run it again and it takes only what is new.

How it gets out

  1. I sign in once, by hand. TinyFish keeps the session as a saved sign-in. No password is in the code.
  2. The Agent reads each Grades page. One TinyFish Agent run per course, read-only, about three steps.
  3. Every reading is checked. Its rows must be the portal's own, and each score must equal the portal's.
  4. A rerun takes only what is new. The Agent goes back only where graded work changed.

Checked, not trusted

The Agent reads each course's Grades page as I see it. Every row it returns is compared with what the portal itself reports.

  • 112 scores the Agent read equal the portal's own
  • 1 differs, and is flagged in the export, not hidden
  • 11 rows the portal holds that the Grades page does not show me

On the first day one run finished "completed" and handed back twelve rows that were on no page. The check refused all twelve. How the check works
